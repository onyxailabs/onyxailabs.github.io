How to Get a YouTube API Key: Create, Restrict, Test (2026)

You get a YouTube API key by creating a free Google Cloud project, enabling the YouTube Data API v3 inside it, and generating a key under Credentials — the whole process takes about five minutes and costs nothing. The two steps most people skip are the ones that matter: restricting the key so it can only call the YouTube API, and understanding the 10,000-unit daily quota before you build anything on top of it.

Step 1 — Create a Google Cloud project

Go to console.cloud.google.com and sign in with any Google account. At the top of the page, open the project picker and choose New Project. Give it a recognisable name — "youtube-tools" is fine — and create it. A project is simply Google's container for your API access: your key, your quota and your usage graphs all live inside it. You do not need a billing account for the YouTube Data API, and creating the project does not charge anything.

Step 2 — Enable the YouTube Data API v3

With your new project selected, go to APIs & Services → Library, search for YouTube Data API v3, open it and click Enable. This is the step beginners most often miss: a key created in a project where the API is not enabled will fail on every call, usually with an error that says the API has not been used in the project. Enable first, create the key second.

Step 3 — Create the API key

Now go to APIs & Services → Credentials, click Create Credentials and choose API key. Google generates the key immediately and shows it once in a dialog — copy it into a password manager or a private note, then click the key's name to open its settings. That settings page is where the important part happens, because a brand-new key is unrestricted: anyone who obtains it can use it against any Google API your project has enabled, spending your quota. Fix that before you use the key anywhere.

Step 4 — Restrict the key (do not skip this)

Two kinds of restriction exist, and you want at least the first one.

API restriction

Under API restrictions, switch from "Don't restrict key" to Restrict key and select only YouTube Data API v3. From now on, even if the key leaks, it can only ever call the YouTube API — it cannot touch your other Google services. This single setting removes most of the real-world risk of an API key, and it takes twenty seconds.

Application restriction

Under Application restrictions you can also limit where the key works from: specific websites (HTTP referrers) for a browser-based tool, or specific IP addresses for a server. If you are pasting the key into a desktop tool that runs on your own machine, leaving this unset is workable — but the API restriction above is not optional. Save the key settings and give Google a few minutes to apply them.

Step 5 — Test the key

A key you have not tested is a hope, not a setup. The fastest honest test is a single read-only call: open your browser and request your own channel's public data by replacing YOUR_KEY in a URL of this shape: youtube.googleapis.com/youtube/v3/channels?part=snippet&forHandle=@YourHandle&key=YOUR_KEY. If the key, the project and the enabled API are all correct, you get a block of JSON containing your channel's public name and description. If something is wrong, the JSON contains an error instead — and the error message tells you which of the three pieces to fix: API not enabled, key invalid, or quota exceeded. A JSON response, good or bad, means you are talking to the real API.

Quota basics — the 10,000 units that run your day

The YouTube Data API is not charged in money; it is charged in quota units, and every project gets 10,000 units per day by default, resetting at midnight Pacific time. Different calls cost different amounts, and the difference is dramatic:

  • Reading data is cheap. Listing a channel, a video or a playlist's details typically costs 1 unit per call.
  • Search is expensive. One search call costs 100 units — so your entire daily budget buys roughly 100 searches a day, and a careless loop can burn the day's quota before breakfast.
  • Errors look alike. When the quota is gone, calls fail with a 403 quotaExceeded error until the reset. It is not a ban and it is not your key breaking; it is an empty tank.

The practical lesson: design tools and habits around reads, and treat searches as a budget. Watch your real usage under APIs & Services → Dashboard in the same project — the graph shows exactly which calls are spending your units.

Keep the key secret — and the BYOK idea

Your key is a password for your quota. Never paste it into a public GitHub repository (automated scanners harvest keys from public code within minutes), never embed it in a web page you publish, and never share screenshots that show it. If a key does leak, delete it in Credentials and create a fresh one — rotation is free and instant.

This is also why well-built YouTube tools ask for your own key instead of shipping theirs — a model called BYOK, bring your own key. Each user's activity spends their own project's 10,000 daily units rather than everyone's traffic draining one shared quota. Our own tool OnyxIQ works this way, which is why this setup is the first step in its guide to what OnyxIQ is: your key, your quota, your data.

Honest limits — what to watch out for

  • An API key is not a login. A key reads public data only. Anything that touches private channel data or manages a channel — uploading, editing your own videos through the API, reading your private analytics — requires OAuth sign-in with the channel owner's consent, which is a separate, more involved setup.
  • The default quota is a ceiling, not a suggestion. More quota exists, but increases are granted by Google after a compliance review, not by paying a fee or toggling a setting.
  • Keys inside browser extensions and desktop apps can be extracted. That is normal for this kind of key; the API restriction from Step 4 is what keeps an extracted key from becoming a serious problem.
  • Do not build on other people's keys. A tool that asks you to paste a stranger's key, or offers you one, is asking you to share someone else's quota and risk — decline.

Frequently asked questions

Is a YouTube API key free?

Yes. The project, the key and the default 10,000 daily quota units cost nothing, and no billing account is required for the YouTube Data API. What you spend is quota, not money — which is why search calls, at 100 units each, are the thing to budget.

Why does my key return a 403 error?

Three causes cover almost every case: the YouTube Data API v3 is not enabled in your project, the day's quota is exhausted (a quotaExceeded message), or your restrictions block the call — for example, an application restriction that does not include the place you are calling from. The error JSON names which one it is; read it before changing anything.

What is the difference between an API key and OAuth?

An API key identifies your project and authorises public, read-only data access. OAuth identifies a person: the channel owner signs in and grants specific permissions, which is what any tool needs to act on a channel. Keys are for reading the public YouTube; OAuth is for touching someone's account.
